# B2 — three-component estimator: the gate, registered before it runs

Written 2026-08-22 ~19:10. The tolerance below is fixed now. If the estimator
misses it, the result is a FAILED gate reported as a book page, not a loosened
bar.

## The model being implemented

Mercolli's three-component form, as specified in the block:

    f(t) = sum_k  I_k * EMG(t; tau_k, t0, sigma)      k = p-Ps, direct, o-Ps
    tau_pPs    = 125 ps   FIXED
    tau_direct = 388 ps   FIXED
    tau_oPs               FREE, the quantity of interest
    t0, sigma             FREE (time zero and Gaussian timing resolution)
    I_k                   FREE, summing to 1, with a Dirichlet(0.75, 3.1, 1.15) prior

EMG is the exponential convolved with a Gaussian, in its numerically stable
form. Binned Poisson likelihood; MAP with the Dirichlet prior, and separately
maximum likelihood with the prior switched off.

**Ordering caveat, stated up front:** the block gives the Dirichlet parameters
as (0.75, 3.1, 1.15) without naming which component each belongs to. Their
means are (0.15, 0.62, 0.23). I assign them in the order (p-Ps, direct, o-Ps)
because that is the only order whose middle and largest component is the direct
one, which every material in our database requires. This assignment is an
assumption, is flagged as such, and the gate is run BOTH with and without the
prior so that no conclusion rests on it.

## The gate

Synthetic spectra are generated from the same model with KNOWN parameters, then
fitted. Truth grid: tau_oPs in {1.50, 1.80, 2.04, 2.40, 2.80} ns, at N = 10^6
and N = 10^5 events, sigma = 90.9 ps (our production value), intensities at the
Dirichlet mean.

**Registered tolerance — all three must hold at N = 10^6:**

- T1  |tau_oPs_hat - tau_oPs_true| <= 1.0 % of truth, at every point on the grid.
- T2  |tau_oPs_hat - tau_oPs_true| <= 3 * sigma_fit, at every point on the grid.
- T3  The recovered o-Ps intensity is within 0.02 (absolute) of truth at every
      point, so the lifetime is not being bought by mis-splitting the intensities.

At N = 10^5 the same three are recorded but only T2 is a pass condition, since
1 % is below the statistical error there.

**A failure of any registered condition is reported as a failed gate. The
estimator does not touch the Mercolli run until it passes.**

## What the gate does NOT establish

Recovering truth from spectra generated by the same model is a self-consistency
check. It proves the fitter and the likelihood are correct; it cannot prove the
three-component form describes real data. That is what the run is for.
